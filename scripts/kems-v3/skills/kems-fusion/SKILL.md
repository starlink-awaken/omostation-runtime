# kems-fusion — 多总结融合

## 触发
用户说"把这些简报/总结/进度表合成一份"或月报撰写前多源口径核对。

## 执行
```bash
python ~/Workspace/projects/runtime/scripts/kems-v3/kems-fusion.py [--neg]
```

## 行为
1. 源抽取：YAML 全量键值 + Markdown 行级关键词
2. 键归一（别名表）+ 语义同义词归一（防假红）
3. 值作用域隔离（跨对象同键不同值，如大兴 2540 vs 归集 300，不误报）
4. 冲突逐对暴露（每个同键异值=1 条）+ SSOT 优先裁决留痕
5. 记录：`~/.kems-pilot/evidence/2026-10-08-p2-fusion.json`

## 验收
- 真实数据 ≥1 条冲突暴露且裁决留痕；`--neg` 注入虚构冲突必须暴露

## 铁律
「未暴露冲突=0 错漏」：所有同键多源值全比对，无静默合并。
